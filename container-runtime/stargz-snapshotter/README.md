# Stargz Snapshotter extension

## Installation

See [Installing Extensions](https://github.com/siderolabs/extensions#installing-extensions).

## Pulling from Private Registries

To pull from private registries an additional step is required. You must configure the Kubelet to use the Stargz snapshotter as an image service proxy. This is explained in more detail in the [Stargz Snapshotter docs](https://github.com/containerd/stargz-snapshotter/blob/main/docs/overview.md#cri-based-authentication).

An example config patch for Talos 1.14 and later (`KubeletConfig` document):

```yaml
apiVersion: v1alpha1
kind: KubeletConfig
config:
  imageServiceEndpoint: unix:///run/containerd-stargz-grpc/containerd-stargz-grpc.sock
```

If the machine config still uses the legacy `.machine.kubelet` section (Talos before 1.14, or a config generated by an older `talosctl`), use instead:

```yaml
machine:
  kubelet:
    extraConfig:
      imageServiceEndpoint: unix:///run/containerd-stargz-grpc/containerd-stargz-grpc.sock
```

## Images Unpacked into the `overlayfs` Snapshotter

Talos sets `discard_unpacked_layers = true` for the CRI plugin, so layer blobs are deleted once an image is unpacked into the `overlayfs` snapshotter.
This affects:

* images pulled before the extension was installed;
* images pulled by Talos itself even with the extension installed, e.g. via `talosctl image pull` or the image pre-pull done by `talosctl upgrade-k8s`, as these always unpack into the default `overlayfs` snapshotter.

Such images are still reported as present, but containerd cannot unpack them into the Stargz snapshotter and container creation fails with an error like:

```text
failed to extract layer (...) to stargz as "extract-...": failed to get reader from content store: content digest sha256:...: not found
```

To fix this, remove the affected images with `talosctl image remove <image>` so that they are pulled again by the CRI, or wipe the `EPHEMERAL` partition after installing the extension.
When upgrading Kubernetes, consider passing `--pre-pull-images=false` to `talosctl upgrade-k8s`.
